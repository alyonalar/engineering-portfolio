# Log analysis: Telegram quiz bot

В каталоге находится обезличенный фрагмент application logs собственного Telegram-бота и его разбор с точки зрения QA и эксплуатации.

## Файлы

- [`sanitized-log-sample.log`](sanitized-log-sample.log) — последовательность событий от запуска приложения до сетевой ошибки;
- [`analysis.md`](analysis.md) — восстановленный пользовательский сценарий и замечания к качеству логирования.

## Что входит в сценарий

- запуск приложения и инициализация базы;
- загрузка и разбор `.docx`;
- создание квиз-сессии;
- правильный и неправильный ответы;
- ручное завершение;
- отклонение неподдерживаемого файла;
- ошибка соединения во время Telegram polling.

Идентификатор пользователя заменён на `User A`. Фрагмент не содержит токены, содержимое документа или Telegram user ID.
